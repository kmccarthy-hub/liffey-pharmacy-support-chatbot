# Liffey Pharmacy Support Assistant

A fictional customer-support chatbot built for an academic assessment. The public interface is hosted on GitHub Pages and its language-model responses are generated by Google Gemini through a secure Vercel serverless function.

## Live website

`https://kmccarthy-hub.github.io/liffey-pharmacy-support-chatbot/`

## Task 1 scope

- Genuine Gemini-generated replies rather than scripted answer matching
- Clear AI and fictional-demonstration disclosure
- General community-pharmacy support boundaries
- No diagnosis or personalised medical advice
- API key held only in the Vercel environment

The assigned Google Sheet and RxNorm integrations are intentionally not included in Task 1.

## Configuration

Vercel requires these environment variables:

- `GEMINI_API_KEY` — entered directly in Vercel and never committed
- `GEMINI_MODEL` — currently `gemini-3.6-flash`

The GitHub Pages frontend reads the Vercel endpoint from `config.js`.
